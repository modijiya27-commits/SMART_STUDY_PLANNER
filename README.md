Smart Study Planner📢


A simple **Python CLI application**that helps students prioritize their study tasks based on Deadline and difficulty.  
This tool is designed for beginners to understand *Python data structures, loops, and functions* while building a practical project.



Features:🧩
- Add tasks with:
  - Subject/Task name
  - Days left for deadline
  - Difficulty level (Easy, Medium, Hard)
- Automatically calculates **priority** for each task
- View tasks **sorted from high to low priority**
- Handles empty task lists safely
